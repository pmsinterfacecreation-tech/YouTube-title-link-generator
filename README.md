# YouTube-title-link-generator
## 🎬 YouTube Title & Link Generator

This project includes a **YouTube Title & Link Generator** tool to quickly create eye-catching YouTube titles and Markdown-ready links for your README or docs.

### 🚀 How to use
1. Open `youtube-title-link-generator.html` in your browser (or host it with GitHub Pages).  
2. Enter a **Video ID** (e.g. `dQw4w9WgXcQ`) or a **Topic/Raw Title** (e.g. `Build an Email Spam Checker`).  
3. Pick a style and click **Generate**.  
4. Copy the suggested title or the Markdown link output.

**Example Markdown output:**
```markdown
[How to Build an Email Spam Checker (Step-by-step)](https://youtu.be/VIDEO_ID)
